# Rust server
## Описание
Данный код - это бот, который будет фоном проверять статус серверов.
На данный момент реализован сбор данных о серверах из следующих игр:
+ Rust
## Функционал
В данный момент бот ничего не умеет, так как он не создан, однако в будущем планируется прописать следующий функционал:
+ Добавление пользовательских серверов
+ Настройка оповещений о конкретных серверах
+ Настройка информации, которая интересна пользователю
+ Просмотр информации по конкретному серверу
+ Добавление серверов из общего списка серверов
## Планы
В данный момент планируется следующее:
+ Сбор информации по отдельным игрокам
+ Добавление мониторинга серверам из других игр
+ Установка фильтров оповещения об изменении данных сервера
# Разработка
Сейчас в разработке находится следующие аспекты:
+ Реализации системы событий для отправки сообщений при обновлении информации о сервере с фильтрацией данных
Следующее на разработке:
+ Рабочий код бота с возможностью сохранять настройки пользователей
